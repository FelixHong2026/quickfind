## 一、小众软件（Appinn）

**投稿方式**：
- 官网右侧「投稿」→ https://www.appinn.com/contact/ （或邮箱 `editor@appinn.com`）
- 也可以在官方论坛 发现频道 发帖

**邮件标题**：
> `投稿：QuickFind —— 能直接跳到文件面前的 Windows 秒搜工具（开源免费）`

**正文**：

```text
编辑你好，

投稿一个自己写的 Windows 免费开源小工具，MIT 协议，无广告无内购无联网。

【一句话】
输入几个字就能秒搜全盘文件，右键即可在 Directory Opus 或资源管理器中
「跳到那个文件面前」——目录打开、文件已选中。

【它解决什么】
搜索工具不缺。Everything 足够快，Listary 也成熟。但常见流程是：
搜到 → 打开所在目录 → 在一堆文件里再找一遍那个文件名。

QuickFind 把最后这一步省掉：右键 → 在 Directory Opus 中定位 →
管理器直接停在该目录并且高亮选中目标文件。

【主要功能】
· 全局热键唤起（默认 Ctrl+Shift+/，可自由改：数字/字母/F 键/符号都行）
· 打字即搜，同时匹配文件名和完整路径，文件夹也能搜到
· 右键在 Directory Opus / 资源管理器中定位并选中
· 5 套皮肤（跟随系统 / 纯黑 / 深灰 / 白底 / 灰度）
· 中英双语，跟随系统语言自动切换
· 点 ✕ 可设为「隐藏到任务栏」或「直接退出」
· 开机自启开关
· 索引自动跳过 AppData、node_modules、虚拟环境、云占位文件、网络盘

【技术信息（供参考）】
· Windows 10/11 x64，约 1,200 行 Python，零第三方依赖
· 索引方式为遍历文件系统写入 SQLite 缓存（不读 NTFS MFT，因此无需管理员权限或服务）
· 实测 47 万条目：建索引约 5 秒，搜索 17-56 ms
· MIT 许可证，源码完整公开

【已知限制（请如实保留）】
· Beta 版本（v0.9.0）
· 索引为快照，新增文件需重建后才会出现
· 仅支持子串匹配，暂不支持模糊匹配与拼音首字母
· 不接管其它程序的「打开/另存为」对话框
· exe 未做代码签名，首次运行 Windows SmartScreen 会提示

【链接】
GitHub（含截图）：https://github.com/FelixHong2026/quickfind
下载：https://github.com/FelixHong2026/quickfind/releases/latest

如需更多截图、使用动图或补充说明，我可以随时提供。
感谢阅读。

FelixHong
fghsxp2026@126.com
```

## 二、少数派（sspai）

**投稿方式**：https://sspai.com/matrix（Matrix 社区）→ 发「创作」类文章
**标题**：
> `不只搜得到，还要跳得到：我写了个把搜索结果直接送进文件管理器的工具`

**文章结构建议**（少数派喜欢"解决问题"的叙事）：

```
1. 引子：一个每天都在发生的小摩擦
   「我知道文件在哪，但我不想点七层文件夹」

2. 现有工具的边界
   · Everything：快，但停在"找到"
   · Listary：有对话框跳转，但闭源
   · 我真正想要的：搜索 → 直接站在文件面前

3. 于是我写了 QuickFind（附界面截图）
   · 热键 → 打字 → 右键 → 文件管理器已定位并选中
   · 5 套皮肤 / 中英双语 / ✕ 行为可配

4. 几个值得一提的技术细节（这是少数派读者喜欢的部分）
   · 为什么不用 MFT：不要服务、不要管理员权限、代码能一下午读完
   · 快捷键捕获的两个坑：Shift 组合键的 keysym 是"字符"不是"按键"；
     有些组合事件根本不到窗口 → 最后改成轮询物理键状态
   · 索引洁癖：云占位文件按属性跳过（不会触发下载）、网络盘跳过

5. 我故意没做的三件事（有取舍才可信）
   · 不注入别人的进程（所以没做对话框跳转）
   · 不和大厂比速度
   · 不做模糊匹配（暂时）

6. 现状与下载
   Beta v0.9.0 / MIT / 地址

7. 结尾：为什么开源
   「不是商业模式，是工作流。希望有人能一下午读懂它、改成自己的。」
```

## 三、投稿心态提醒

| 事项 | 说明 |
|---|---|
| **媒体可能不回** | 正常。小众软件/少数派投稿量很大，被忽略不代表东西不行 |
| **一次只投一家** | 别群发同一封邮件，编辑能看到 |
| **隔两周可再试** | 如果第一次没回，改过版本号（比如 v0.9.1）后再投一次，说明"已更新" |
| **准备好答问** | 编辑可能会问"能不能给个 GIF"——所以**录个 5 秒动图很有用** |
| **别催** | 催稿基本等于放弃 |
